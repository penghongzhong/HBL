# 实际 Hamilton 光滑图的单值性

固定半直线能量坐标 $q_f=(rf)'\in L^2(0,\infty)$。本轮构造关系

$$
\mathcal G(q,y):\quad
q=(q_f,q_v),\quad y=(q_a,q_b),\qquad
ra=H_-(rv),\quad rb=-H_+(rf)\quad(r>0),
$$

其中 $f,v\in C^2(\mathbb R)$，$a,b\in C^1(\mathbb R)$，四个能量坐标均属于实际半直线 $L^2$。$H_+$ 是仓库既有的非局部 Hartree 算子，未替换成局部模型。

已证：$q_f=q_g$ 且 $f,g\in C^1$ 时，$f=g$ 于 $(0,\infty)$。证明将 $L^2$ 坐标相等转成导数几乎处处相等，在每个 $(0,R)$ 积分，再用 $(rf)(0)=0$ 的微积分基本定理恢复剖面。负半轴的任意延拓不影响结论。

实际 $H_-$ 与 $H_+$ 均只依赖正半轴剖面：局部项由邻域相等及两次导数相等得到，非局部项由定义积分内的几乎处处相等得到。由此证明

$$
\mathcal G(q,y)\land\mathcal G(q,z)\quad\text{则}\quad y=z.
$$

这排除了能量等价类或原点端点导致的输出歧义。尚未证明该图的线性、闭性、可闭性、投影定义域的稠密性，或它生成实际演化；也未声称该图定义在每个能量向量上。下一步须证明实际算子的共同核心及其闭包性质。
