## 1. 本次核对的真实目标

已对照仓库提交 `54470bb83b5c3da067dfb3b30f6a07ce1909ffe5` 的 `verification/typeii-minimal-main-replacement.tex`、`HBL/FiniteProfile.lean`、`HBL/OneLayerElimination.lean`、`HBL/TransversalityExact.lean`，以及 Library 主链稿 `HBL_DynamicTypeII_13_MainChain_20261101.tex` 中 `thm:finite-profile-stage3` 的完整陈述与证明。

主定理不变：从真实 Hartree PDE 构造有限时径向单泡 II 型轨道，且集中速率由动力学导出，不预设速率、不以投影消去或可逆性代替待证结论。

第 2.13 要求真实三域剖面 V_N，而不仅是一个有限和：

    F_PDE(V_N) = P_N zeta_s + E_N,
    ||E_N(s)||_(X_f^sc) <= C s^(-N),
    N > M+3+ell_lr, M>4,
    D_zeta Theta_N = I_2 + o(1),

以及实际 Hessian 的慢项/可积项分解、参数控制和所需局部 Lipschitz 性。

## 2. 已确认的停滞原因

### A. 结构递推与真实残差之间尚无完整连接

`GeneratedTerm.order` 在 `OneLayerElimination.lean` 中被定义为

    rho + gain(cause) + extra, extra>=0.

所以标签的阶大于 rho 不能替代实际生成函数的加权范数估计。`finiteProfile_recursion_certified` 还显式接收 `hstep`，且其任意有限 packets 列表没有与 rho 序列或实际 Hartree 残差绑定。它是正确的条件性结构工具，不是实际剖面构造。

本次新增 `HBL/Verification/FiniteProfileScopeRegression.lean`：直接实例化现有结构终端的空 packets 情形，同时用原 `complexRadialRenormalizedResidual` 计算一个平滑径向探针在 s=0,r=1 的残差为 i。它检验的是验收范围，不是反驳论文主定理，也不证明任何已正确表述的条件定理有错。其 CI 成功只能算范围回归测试通过，论文增量必须为零。

### B. 绝对小量不是每一层的相对增阶

此前基础源、迹和匹配残差的 ell^(1/16) 界有真实价值，但没有证明任意 V_j -> V_(j+1) 的新残差相对于旧残差提升。按陷获窗口 lambda(s)>=c*s^betaMinus，它最多直接给出 s^(-betaMinus/16) 级别的上界；不能重复引用同一个界，把指数自动累加到任意 N。

### C. 已验证的不同雅可比不能互换

`mainJet=id` 是归一化首 Laurent 系数的恒等式。源投影的两个列是另一个对象。完整物理匹配映射还含同一规范化内区解的响应：固定基底/界面时列应为

    L_R(J_b) - Pi_K(P_b),
    L_R(J_omega) - Pi_K(P_omega).

基底和界面变化时还有相应导数。不得用源投影矩阵或 `mainJet_fderiv` 替代这个完整矩阵。真实矩确定的 c_s 也不能变成额外自由速度。

### D. 把“剩两个编号”误读成“剩少量工作”

11/13 是修订版环境账本，不是证明工作量、风险或完成概率。剩下的全阶剖面与真实 PDE 构造包含主要分析负担。4000 余 Lake 任务的成功、模块个数、辅助引理个数均不是该比例的分子。

## 3. 即日起的单一主链验收门槛

后续任何开发先标明它关闭以下哪个确切义务，及终端定理如何使用。无对应者暂停，不再为了取得新 CI 成功扩展旁支。

1. **真实耦合校正的可解性**：由已有固定 Fredholm 逆构造两个实际内区源响应及其物理迹；组装完整耦合匹配映射，证明真正需要的非退化性或给出与原 PDE 等价的替代消去机制。不得先假设逆雅可比。
2. **一个真实非平凡步骤的相对增阶**：从明确的 V_j、其原 PDE 残差和上述校正出发，逐项保留时间项、三域截断、全部非局部项、参数项及远区项，证明在论文真实范数中

       ||F_PDE(V_(j+1)) - P_(j+1) zeta_s||_(X_f^sc)
          <= C_j s^(-(rho_j+kappa)), kappa>0.

   不能将该不等式作为新结构字段、`hstep`、`GeneratedTerm.order` 的定义或新增主定理前提。先完成这一实际步骤，再扩展到有限递推。
3. **完整目标签名复验**：上述实现接入现成有限递推工具，且核对实际 Theta_N、Hessian、参数/差分和远区对应。只有最后的导出声明覆盖原目标，才能验收 2.13。
4. **真正的 PDE 轨道与选速**：由已完成剖面和现有稳定性/射击工具导出解及速率。不能把极限指数、陷获轨道存在或终端匹配提前当作结论使用。

这些是数学验收条件，不是声称可以通过检查若干源码关键词自动保证语义等价。

## 4. 允许的有意义缩短

主定理只要求存在至少一个轨道。可研究将中间结论收缩到一个固定合法终端辐射和一个满足后续稳定性需求的有限 N0，而不证明所有 g、所有 N 的最强族定理。只有在核对所有下游引用、所需参数 Lipschitz 性和能量匹配仍足够后，才能正式采用此修订。当前尚未把这项可行的缩减记为已证明。

固定 Kummer 坐标环带上的原 Green 估计已经具备；不要为了扩大一般性再要求没有下游用途的任意移动环带一致性。若实际构造确实需要移动界面，则必须在真实换元与权重中验证其常数，不能隐藏为统一常数。

## 5. 立即停止的绕路

- 停止重复改良基础核心—辐射源、已固定环带上的标量 Green 界或已验收的局部迹存在性，除非具体终端缺口确实要求更强版本。
- 停止为有限秩辅助源另造“物理解释”；只能从原 PDE 的真实速度方向及同一内区解响应证明对应。
- 停止把新增定理的名字、模块数或 CI 任务数作为论文接近完成的证据。
- 不删除已验收源码；作为证明池复用。沿用当前分支与精确工具链缓存，按一个阻塞点做一次联合验收，避免并行漂移成多个不等价问题。
